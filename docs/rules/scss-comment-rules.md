# SCSSコメントヘッダー運用ルール

## 目的

`scss` / `module.scss` ファイル先頭のコメント表記を揃える。

## 対象

- `src/**/*.scss`
- `src/**/*.module.scss`

## 記載ルール

- ファイル先頭に記載する
- `URL` はプロジェクト内パスで統一する
- 修正したら `Last updated` を更新する

## テンプレート

```scss
/* =======================================
 * センターリバー スタイル名
 * URL: src/styles/example.module.scss
 * Created: 2026-07-10
 * Last updated: 2026-07-10
 * ======================================= */
```
