# TSXコメントヘッダー運用ルール

## 目的

`tsx` ファイル先頭のコメント表記を揃える。

## 対象

- `src/**/*.tsx`

## 記載ルール

- `import` の前に記載する
- `URL` はプロジェクト内パスで統一する
- 修正したら `Last updated` を更新する

## テンプレート

```tsx
/* =======================================
 * センターリバー ページ名 or コンポーネント名
 * URL: src/app/example/page.tsx
 * Created: 2026-07-10
 * Last updated: 2026-07-10
 * ======================================= */
```
