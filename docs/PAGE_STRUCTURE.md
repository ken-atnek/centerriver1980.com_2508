## ページ別メモ

### 当店のこだわり＆オススメメニュー `/concept/`

- 目的: ブランドの考え方と主力メニューを伝える
- 主な内容:
  - こだわり紹介
  - おすすめメニュー導線
  - PDFメニュー導線

### オンラインショップ `/products/`

- 目的: 通販商品への導線と購入補助情報をまとめる
- 主な内容:
  - 商品一覧
  - シェフ動画
  - 購入案内

### センターリバーのお弁当 `/takeout/`

- 目的: テイクアウト / 配達案内を伝える
- 主な内容:
  - メニュー
  - 受付時間
  - 販売店舗情報

### お知らせ `/news/`

- 目的: 最新情報、営業案内、更新情報を掲載する

### 店舗案内 / 会社概要 `/company/`

- 目的: 店舗情報と会社情報をまとめる
- 主な内容:
  - 店舗一覧
  - 会社概要
  - 経営理念 / 社是 / 社訓
